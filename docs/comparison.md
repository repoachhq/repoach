## PR sources, not competitors

These open the pull requests that a reviewer then reads; repoach works after them, not instead of them.

- **OpenHands**: an autonomous developer that opens PRs; repoach reviews and gates them.
- **Devin**: an autonomous developer that opens PRs; repoach reviews and gates them.
- **SWE-agent**: an agent that turns an issue into a patch; repoach reviews and gates the PR.
- **Aider**: a local coding assistant whose commits reach a PR; repoach reviews and gates it.
